# Proiectele lui Daniel

Catalog în limba română pentru proiectele găsite în spațiul de lucru al acestui calculator. Fiecare proiect are propria pagină HTML la `proiecte/<nume>.html`, iar prima pagină oferă căutare, filtre și linkuri către toate paginile.

## Conținut

- 20 pagini de proiect, cu descrieri bazate pe fișierele locale.
- Linkuri către variantele publice și repository-urile confirmate.
- Atribuire explicită pentru repository-urile de origine aflate în alte conturi.
- Design adaptat pentru telefon și desktop.

## Regenerare

Rulați `py build.py` după modificarea listei `projects` din `build.py`. Fișierele HTML sunt generate în rădăcina repository-ului.

## Publicare pe GitHub Pages

Repository-ul recomandat este `DANIELluntras.github.io`. În setările GitHub Pages selectați **Deploy from a branch → main → /(root)**. Adresa va fi `https://danielluntras.github.io/` după publicare.

Acest catalog nu include cod sursă sau date private ale proiectelor enumerate. Folderele locale sunt prezentate ca informație, nu ca linkuri web.
